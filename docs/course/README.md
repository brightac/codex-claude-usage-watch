## 怎么交付这门课

你的目标是**拍脚本课程**（一个脚本 → 一门课），所以：

### 主交付：视频 + 文档即脚本
两篇 md 天生就是**分镜脚本**（每集"痛点→动作→教学点→坑"）：
- 一集 = 一个视频片段；"教学点" = 口播要点；截图/CLI = 画面素材；"坑" = 最抓人的冲突反转。
- 平台：**视频号 / B 站 / YouTube**（跑步+讲AI 的主线渠道）。

### 配套书面课：选一个"在线知识库" + 一份 PDF
| 方式 | 适合 | 优点 | 缺点 |
|---|---|---|---|
| **飞书知识库**（推荐主力） | 中文受众、要持续迭代 | 在线、可评论、嵌图方便、能一键导出 PDF、分享链接即用 | 需飞书账号看全功能 |
| **PDF**（推荐做引流款/讲义） | 可下载、朋友圈/私域分发 | 极简、离线、当"引流款"发 | 静态、难更新、图多体积大 |
| **GitHub（本仓库）** | 开发者受众 | 版本可控、代码同源、可信 | 非技术受众门槛高 |
| 语雀 / Notion / GitBook | 结构化在线课站 | 目录清晰、适合长期课 | 又多一个平台要维护 |

**推荐组合**：
1. **视频**为主交付（对着 md 脚本拍）；
2. **飞书知识库**放"活文档"（随反馈迭代，学员可评论提问）；
3. 从飞书**导出一份 PDF** 作为可下载讲义 / 私域引流款；
4. **GitHub 仓库**作为"源码真相"，视频/文档里都链过去。

> 更"流行"的做法其实是**多端一鱼多吃**：一套 md 素材 → 拍视频 + 飞书在线文档 + 导出 PDF + GitHub 源码。写一次，四处发。

### 想做付费课？
- 轻量：**知识星球 / 小报童**（把飞书文档 + 视频打包进去）；
- 正式：挂到**在线课平台**，PDF 当试看讲义引流。
